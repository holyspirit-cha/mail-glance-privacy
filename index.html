Mail Glance Privacy Policy

Effective date: September 28, 2026

1. Information we handle

Mail Glance does one thing. When you hover over an email in your Gmail or Naver Mail inbox, it summarizes that email with AI and shows the result in a card.

InformationWhenWhere it goes
Email subject, sender, body (last 4,000 characters) and attachments (up to 3, 3 MB each)Only when you hover over an emailThe Anthropic API (api.anthropic.com), using the API key you obtained and entered yourself
Event title, date, summary and the email's attachmentsOnly when you click "Add to Calendar"Your own Google Calendar and Google Drive
Your Anthropic API key and settings (model, excluded domains)When you save them on the settings pageStored only inside your browser (chrome.storage.local)
Summary resultsRight after a summary is madeBrowser session storage, deleted when you close the browser

2. The developer receives nothing

This extension has no developer server. Email content, API keys and event details are never sent to the developer. We use no advertising, analytics or tracking tools. We do not sell user data, share it with third parties, or use it for anything other than the extension's single purpose.

3. Reading email content

For Gmail, the extension reads the email's print view from the same origin inside the browser where you are already signed in. It does not use the Gmail API. For Naver Mail, it uses only the subject, sender and preview shown in the inbox list.

4. Google user data

Google sign-in is requested only the first time you click "Add to Calendar". The extension asks for two scopes: calendar.events to create events, and drive.file to access only the files this extension uploads. Data received from Google is used only to create the event you asked for. Mail Glance's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The access token is kept only in browser session storage and is deleted when you close the browser.

5. Third-party processing (AI summaries)

To make a summary, email content is sent to the API of Anthropic PBC. That processing is governed by Anthropic's terms and privacy policy, and the contracting party is you, the owner of the API key. Emails from senders listed under "Excluded domains" in the settings are never sent.

6. Deletion

Removing the extension deletes the API key, settings and cache stored in your browser. You can delete events and Drive files yourself in Google Calendar and Google Drive.

이 확장 프로그램에는 개발자 서버가 없습니다. 메일 내용·API 키·일정 정보는 개발자에게 전송되지 않으며, 광고·분석·추적 도구를 쓰지 않습니다. 사용자 데이터를 판매하거나 제3자에게 제공하지 않으며, 확장 프로그램의 단일 목적 외에는 사용하지 않습니다.

3. 메일 본문 읽기

지메일 본문은 사용자가 이미 로그인한 브라우저 안에서 지메일 인쇄보기 화면을 같은 출처로 읽어 옵니다. Gmail API 는 사용하지 않습니다. 네이버 메일은 목록 화면에 표시되는 제목·발신자·미리보기만 사용합니다.

4. Google 사용자 데이터

구글 로그인은 사용자가 「캘린더에 등록」을 처음 눌렀을 때만 요청하며, 권한은 calendar.events(일정 생성)와 drive.file(이 확장이 올린 파일만 접근) 두 가지뿐입니다. 받은 데이터는 사용자가 요청한 일정 생성에만 쓰며, Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 준수합니다. 액세스 토큰은 브라우저 세션 저장소에만 보관되며 브라우저를 닫으면 삭제됩니다.

5. 제3자 처리(AI 요약)

요약을 위해 메일 내용이 Anthropic PBC 의 API 로 전송됩니다. 처리는 Anthropic 의 이용약관·개인정보처리방침을 따르며, 계약 당사자는 API 키를 발급받은 사용자 본인입니다. 설정의 「제외 도메인」에 적은 발신자의 메일은 전송하지 않습니다.

6. 삭제

확장 프로그램을 제거하면 브라우저에 저장된 API 키·설정·캐시가 모두 삭제됩니다. 등록된 일정·드라이브 파일은 사용자가 Google 캘린더·드라이브에서 직접 삭제할 수 있습니다.
